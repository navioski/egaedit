# PxPlus IBM VGA8

`PxPlus_IBM_VGA8.ttf` is used **only** by `tools/ansi2png.py` to render the
documentation screenshots in `docs/`. The editor itself never loads it: a
terminal TUI draws with whatever font the terminal is configured with.

- Font: *PxPlus IBM VGA8*, part of VileR's [Ultimate Oldschool PC Font Pack](https://int10h.org/oldschool-pc-fonts/)
